# Overview

The **FortiSOAR SOC Simulator** solution pack helps you experience the power and capability of FortiSOAR incident response for SOC simulation scenarios. This pack contains utilities for demonstrating FortiSOAR capabilities around a variety of important SOC use cases without having to integrate with actual device endpoints.

Scenarios ship with other solution packs, such as **Stolen Credential Leading to Data Exfiltration**. The SOC Simulator provides the framework that runs them: the Scenario module that lists the available scenarios, the playbooks that create and remove the demo records, and the Scenario Simulator widget that runs a simulation from a record list page.

Use the SOC Simulator to evaluate FortiSOAR without connecting external security tools, demonstrate incident response workflows to stakeholders, train analysts on triage and escalation, and validate playbooks against repeatable inputs. Resetting a scenario removes every demo record it created, returning the environment to its original state.
